2. Estructuras de Datos

Vectores (Arrays)

Los vectores son estructuras de tamaño fijo que almacenan elementos del mismo tipo. Se deben declarar e instanciar indicando su longitud.

// 1. Declaración e instanciación
int[] miVector;
miVector = new int[10]; 

// 2. Llenado usando la clase Random
Random numeroAleatorio = new Random();

for (int i = 0; i < miVector.Length; i++)
{
    miVector[i] = numeroAleatorio.Next(1, 1000);
}

// 3. Recorrido y muestra en consola
Console.WriteLine("long=" + miVector.Length);

for (int i = 0; i < miVector.Length; i++)
{
    Console.WriteLine(miVector[i]);
}

Listas Genéricas (List<T>)

A diferencia de los vectores, las listas son dinámicas. Pueden crecer o encogerse en tiempo de ejecución a medida que agregamos o quitamos elementos.

// 1. Declaración e instanciación de una lista de enteros
List<int> miLista;
miLista = new List<int>();

// 2. Agregar elementos (se añaden al final)
miLista.Add(2);
miLista.Add(6);
miLista.Add(1);
miLista.Add(4);

// 3. Operaciones útiles
miLista.Sort();    // Ordena la lista de menor a mayor
miLista.Remove(4); // Busca y elimina la primera aparición del número 4

// 4. Recorrido usando foreach (Ideal para listas)
foreach (int elemento in miLista)
{
    Console.WriteLine(elemento);
}

// 5. Recorrido alternativo usando for y la propiedad Count
for (int i = 0; i < miLista.Count; i++)
{
    Console.WriteLine("El elemento " + i + " es " + miLista[i]);
}

3. Clases y Arquitectura Base

En C#, todo el código debe estar encapsulado dentro de clases. La ejecución de un programa de consola comienza siempre en un método estático especial llamado Main.

using System; // Importa funcionalidades básicas (ej. Console)

namespace pruconsola 
{
    // Definición de una clase propia
    class clase1
    {
        // Atributos con modificadores de acceso
        public int uno;
        protected int dos;

        // Método de la clase
        public void metodo1()
        {
            Console.WriteLine("Soy metodo 1");
        }
    }

    // Clase principal que contiene el punto de entrada
    class Program
    {
        static void Main(string[] args)
        {
            // Instrucción directa
            Console.WriteLine("Hola");
            
            // Instanciación (Creación de un Objeto a partir de la clase)
            clase1 miObjeto = new clase1();
            
            // Llamada a un método del objeto
            miObjeto.metodo1();
        }
    }
}

4. Métodos y Propiedades Más Útiles en C#

Manejo de Consola (System)

  • Console.WriteLine()
    Imprime un texto o variable y salta a la siguiente línea.
  • Console.Write()
    Imprime pero mantiene el cursor en la misma línea.
  • Console.ReadLine()
    Detiene la ejecución esperando que el usuario ingrese texto por teclado.

Manejo de Listas (List<T>)

  • .Add(elemento)
    Inserta un nuevo elemento al final de la colección.
  • .Remove(elemento)
    Busca y elimina un elemento específico.
  • .Sort()
    Ordena los elementos de la lista en orden ascendente.
  • .Count (Propiedad)
    Devuelve la cantidad actual de elementos en la lista.

Vectores y Generación Aleatoria

  • miVector.Length (Propiedad)
    Devuelve el tamaño total (capacidad) del vector definido en su instanciación.
  • random.Next(min, max)
    Genera un número entero aleatorio comprendido entre el valor min (incluido) y el valor max (excluido).

5. Recomendaciones y Proyectos Sugeridos

Buenas Prácticas en POO

  • Encapsulamiento: Usa private o protected para los atributos de tus clases y expón su comportamiento mediante métodos public.
  • Nomenclatura: Nombra las Clases en PascalCase (ej: MiClase) y las variables/objetos en camelCase (ej: miVector).
  • Preferir Listas: Si no conoces la cantidad exacta de elementos que vas a guardar desde el principio, utiliza List<T> en lugar de Vectores fijos.
