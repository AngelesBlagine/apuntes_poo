2. Sockets y Streams

Un Socket es el punto final de una conexión de red bidireccional. Está compuesto por dos elementos clave:

Socket = IP + Puerto

Una vez que dos Sockets se conectan (el del Cliente y el del Servidor), se comunican enviando y recibiendo información a través de Streams (flujos de datos).

3. Implementación del Servidor

El servidor debe instanciar un ServerSocket en un puerto específico y quedar a la espera ("escuchando") de conexiones entrantes de clientes. Al aceptar a un cliente, se debe delegar su atención a un hilo nuevo (Thread) para poder seguir esperando nuevos clientes.

ServidorPrincipal.java 
import java.net.*;
import java.io.*;

public class ServidorPrincipal {
    public static void main(String[] args) {
        int PUERTO = 60001; 
        System.out.println("\nArranca Servidor...");
        ServerSocket socketServidor = null;

        try {
            // 1. Abrimos el puerto en el servidor
            socketServidor = new ServerSocket(PUERTO);
        } catch(Exception e) {
            System.out.println(e.getMessage());
        }

        while (true) {
            Socket cliente = null;
            try {
                // 2. El servidor se pausa aquí hasta que se conecta un cliente
                cliente = socketServidor.accept(); 
            } catch(Exception e) {
                System.out.println(e.getMessage());
            }

            // 3. Se delega la conexión a un Hilo (Runnable)
            ServidorEscucha nuevoCliente = new ServidorEscucha(cliente);
            Thread hilo = new Thread(nuevoCliente); 
            hilo.start(); 
            // El ciclo vuelve arriba a esperar otro cliente
        }
    }
}
ServidorEscucha.java (El Hilo de atención) 
public class ServidorEscucha implements Runnable {
    Socket elCliente;
    DataOutputStream salida;
    BufferedReader entrada;
    String leido;

    public ServidorEscucha(Socket cliente) {
        elCliente = cliente; // Guardamos el socket del cliente particular
    }

    public void run() {
        System.out.println("Conexión: IP=" + elCliente.getRemoteSocketAddress() + " Puerto=" + elCliente.getPort()); 
        try {
            // Configuramos Streams de Salida y Entrada
            salida = new DataOutputStream(elCliente.getOutputStream());
            entrada = new BufferedReader(new InputStreamReader(elCliente.getInputStream()));
            
            salida.writeBytes("Hola Cliente!\n"); 
            
            while(true) {
                // Leer del cliente
                leido = entrada.readLine();
                System.out.println("Leido: " + leido);
                // Responder al cliente (Eco)
                salida.writeBytes("Eco del Servidor: " + leido + "\n"); 
            }
        } catch(Exception e) {
            System.out.println(e.getMessage());
        }
    }
}

4. Implementación del Cliente

El cliente necesita instanciar la clase Socket apuntando a la dirección IP del servidor (o localhost si es la misma máquina) y al puerto correcto.

ClienteMain.java 
import java.net.*;
import java.io.*;
import javax.swing.JOptionPane;

public class ClienteMain {
    public static void main(String[] args) {
        int PUERTO = 60001;
        Socket cliente = null;
        String s = "";
        BufferedReader entrada = null;
        BufferedWriter salida = null;

        try {
            // 1. Nos conectamos al servidor
            cliente = new Socket("localhost", PUERTO);
            
            // 2. Configuramos Streams
            entrada = new BufferedReader(new InputStreamReader(cliente.getInputStream()));
            salida = new BufferedWriter(new OutputStreamWriter(cliente.getOutputStream()));
            
            while (true) {
                // Leemos lo que manda el servidor (se bloquea hasta recibir algo)
                while((s = entrada.readLine()).length() == 0) {}
                System.out.println("Servidor dice: " + s);
                
                // Escribimos al servidor usando una ventana gráfica de entrada
                String mensaje = JOptionPane.showInputDialog("Mensaje para enviar:");
                salida.write(mensaje + "\n");
                salida.flush(); // Fuerza el envío de los datos en el buffer
            }
        } catch(Exception e) {
            System.out.println(e.getMessage());
        }
    }
}
Nota sobre el Cliente: En un programa real avanzado de chat, si usamos readLine() en el hilo principal del cliente, bloquearemos la Interfaz Gráfica (UI) impidiendo que el usuario escriba mientras espera recibir un mensaje. Por eso se requiere usar hilos también del lado del cliente.

5. Arquitectura de un Cliente de Chat

Para lograr que un cliente reciba mensajes en tiempo real mientras simultáneamente permite escribir y enviar mensajes, es fundamental dividir las responsabilidades en múltiples hilos (Threads).

El rol de cada Hilo

  • Hilo 1

    Maneja la conexión a nivel de red y mantiene vivo el Socket.

  • Hilo 2

    Se dedica exclusivamente a escuchar la interfaz gráfica (UI) y escribir hacia el OutputStream. Como está en su propio hilo, la UI nunca se congela.

  • Hilo 3

    Posee un bucle infinito escuchando el InputStream. Se queda bloqueado allí, pero como es un hilo separado, no afecta al envío de mensajes.
